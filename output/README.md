# Salidas de trabajo

El inventario guarda aquí `inventario_archivos.csv` e `inventario_columnas.csv`. Posteriormente podrán generarse tablas, figuras y métricas. Quarto genera los entregables en `docs/quarto/`, también fuera del historial. Registrar en `docs/ENTREGAS.md` qué versión se entregó y dónde se conserva.
