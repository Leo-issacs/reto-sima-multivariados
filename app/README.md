# Interfaz para utilizar el modelo

El enunciado solicita una interfaz gráfica. Su alcance exacto debe confirmarse con las profesoras en la semana 3, para implementarla en la semana 4.

Propuesta de mínimo: una sola interacción directamente vinculada al método elegido y una salida interpretable con unidades, población/periodo de aplicación y limitaciones. R Shiny es una opción si se necesitan cálculos reactivos; no se instala ni se implementa todavía.

Antes de construir, registrar aquí: usuario, pregunta que resolverá, entradas, salida, casos fuera de alcance y forma de demostración. Un panel de gráficas descriptivas no cumple automáticamente el requisito de utilizar un modelo.

Comprobar después: entrada válida, dato ausente, valor fuera del ámbito, resultado coincidente con el script y mensajes comprensibles. El despliegue público solo se planteará si forma parte del requisito confirmado.
